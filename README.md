# Ровная спина

Щадящая программа силовых тренировок для спины: ролики техники, подходы и веса,
таймер отдыха, кора по McGill каждый день, кардио, история и предложения по росту нагрузки.

Статическое PWA без бэкенда, аналитики и трекеров. Все записи хранятся только в localStorage устройства
(экспорт и импорт в JSON/CSV — в настройках). Ролики анимированы в Blender и собраны скриптами исходного проекта.

Приложение не заменяет консультацию врача.
